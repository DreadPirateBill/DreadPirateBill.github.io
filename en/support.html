Which devices does Sprocket Player run on?

Apple TV running tvOS 18.6 or later, and iPad running iPadOS 17.6 or later. It is not available for iPhone.

Does Sprocket Player need Plex, Jellyfin or Emby installed?

No. A shared folder on your NAS or computer works on its own, and Sprocket shows any posters and descriptions saved alongside your files. If you already run Plex, Jellyfin or Emby, sign in and Sprocket uses the server's library and artwork directly.

Sprocket can't connect to a share on my Windows PC. What should I check?

Sprocket Player needs SMB version 2 or later. If SMB2 has been turned off on the PC, turn it back on in Windows and try again. Also check that file sharing is enabled and that the user name and password are correct.

How do I sign in to Plex or Jellyfin on Apple TV?

Choose Authenticate on the Add Source form. The TV shows a short code and a QR code. Approve the code at plex.tv/link or in any signed-in Jellyfin client, and the TV finishes on its own. If a Jellyfin administrator has switched Quick Connect off, choose Use a Password Instead. Emby uses the phone setup form.

Why did a video play as a converted stream?

On a media server, Sprocket plays the original file whenever it can. It asks the server to convert only when this device can't decode the codec, the connection is too slow for the file, or the server is outside your network. A notice says which.

Where is my data stored?

Entirely on the device. Sign-in details live in the system Keychain, and saved thumbnails and library details are always encrypted. See the privacy policy for the full picture.
